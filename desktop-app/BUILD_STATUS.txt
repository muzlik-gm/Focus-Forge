BUILD COMMAND
-------------
To build the production executable:
  cd desktop-app
  npm run build

This will:
1. Build Next.js as static export
2. Compile Rust backend
3. Bundle everything into a single .exe file
4. Create installer in: desktop-app/src-tauri/target/release/bundle/

OUTPUT LOCATION
---------------
After build completes, the executable will be at:
  desktop-app/src-tauri/target/release/forgrin-desktop.exe

And the installer will be at:
  desktop-app/src-tauri/target/release/bundle/msi/Forgrin_0.1.0_x64_en-US.msi
